## Порядок работы

1. Перед вопросами о рейсах, отелях, билетах, маршруте, времени, расходах и чек-листах читать **текущую версию Google Docs** через подключённый Google Drive.
2. При подтверждённых изменениях сначала обновлять Google Docs, затем при необходимости **сайт в этом GitHub-репозитории**.
3. Сайт — представление плана; при обновлении сохранять дизайн, фотографии, навигацию, ссылки, интерактивные чек-листы, функциональность бюджета и другую действующую функциональность.
4. Не использовать этот Markdown или старые файлы проекта как актуальный мастер. Не заводить параллельных мастеров.
5. Вести отдельно оплаченные расходы, будущие платежи, возвратные депозиты и доступный денежный запас; суммы по умолчанию показывать в рублях.
6. При отсутствии доступа к Google Docs не подменять его сведениями из старых версий; сообщить об ограничении.

**Примечание о приватности:** этот GitHub-репозиторий публичный, а Google Docs — закрытый. Исторические коммиты GitHub всё ещё могут содержать прежнюю полную сводку: замена текущей версии Markdown не удаляет содержимое старых коммитов.
